# ComicCraft - AI Comic Story Creator using Gemini Models

ComicCraft is an AI-powered web application that transforms your imagination into complete comic stories using Google's Gemini Models.

Just enter a single story idea and get a full comic with characters, dialogues, scenes, and illustrated panels.

### ✨ Features
- AI Story Generation with Gemini
- Auto Character & Dialogue Creation
- Comic Panel Generation
- Export as PDF / Image
- User-friendly Interface

### 🛠️ Tech Stack
- Google Gemini API
- Python / JavaScript
- Streamlit / React
- Generative AI

### 🚀 How it Works
1. Enter your story prompt
2. Gemini generates the comic script
3. App creates panels with images & text
4. Download your comic!

### 🎯 Use Cases
- Kids Story Learning
- Content Creators
- Educators
- Fun & Entertainment
